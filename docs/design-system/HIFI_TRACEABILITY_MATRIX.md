## Contract

This matrix does **not** approve final high-fidelity visuals. It freezes what each canonical state must become or reference during later Issue #17 design phases.

Required fields per state: **WF / UF / State / GS / Priority / Ownership**. A state that is not part of GS-01..GS-05 retains the explicit value `— (not on GS-01..05 path)`; this is a valid assigned GS disposition, not a missing field.

Initial high-fidelity disposition types:

- **DEDICATED_HIFI** — reviewable app-visible high-fidelity visual + paired Markdown spec.
- **HIFI_VARIANT_ANNOTATION** — variant/annotation inside the owning high-fidelity screen/component; no separate destination is invented.
- **SYSTEM_ONLY_HANDOFF** — Android/system/provider/MediaSession handoff annotation only; no app high-fidelity destination.
