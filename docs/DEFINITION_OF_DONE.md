# Definition of Done

A task is Done only when all applicable conditions are met.

## Product

- Acceptance criteria are satisfied.
- Empty, loading, success, and error states are handled.
- Copy and UX match the approved design.
- Scope changes are documented.

## Engineering

- Code is reviewed through a pull request.
- Relevant tests pass.
- No secrets or sensitive user data are committed or logged.
- Failure and recovery behavior are explicit.
- Accessibility and localization implications are checked.
- Documentation is updated when behavior or architecture changes.

## Quality

- The change is verified on a representative device or emulator.
- Crash and analytics events are tested when affected.
- No unresolved critical or high-severity defect remains.
- The issue contains verification evidence.

## Release

- User-visible changes appear in release notes.
- Configuration is environment-safe.
- Rollback or disable strategy is understood.
