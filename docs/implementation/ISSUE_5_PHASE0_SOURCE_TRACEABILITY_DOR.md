## 3. Frozen behavioral requirements

- **WF-01 / S-01 startup:** truthful migration/permission/media readiness; recoverable startup failure, never false Ready.
- **WF-02 / S-02 / CA-01 onboarding:** at most **2 value introduction slides**; Continue or Skip; completion persisted only after DataStore write ACK; interruption resumes the actual pending step; Replay from Settings is educational and **non-mutating** (permissions, scan/index, queue and playback unchanged). Exactly six Voice command education examples from accepted mapper; Practice is optional.
- **WF-03 / S-03 / SYS-01/02/04:** explain media before first scan; **mic only after explicit mic action or chosen Practice**; OS permission truth is authoritative. Granted resumes capability, requestable Denied offers Retry and Not now, Permanent offers Open Settings and Not now. **Settings return explicitly rechecks all three cases**; no automatic Settings loop, no coercion and manual fallback preserved.
- **SYS-03 notification:** request **only where platform version requires**, after successful playback/background-controls value, with denial preserving service-owned playback; baseline manifest lacks POST_NOTIFICATIONS.
- **SYS-05 provider:** availability, mic grant and any remote speech consent are separate decisions. Foundation selects an on-device provider fail-closed; **remote/cloud STT remains disabled** unless processor/destination/purpose/retention/withdrawal disclosure and Privacy/Legal approval are real.
- **WF-04 / S-04 / GS-01:** first scan starts only with actual platform access; MediaStore is source of accessible media existence, Room index is rebuildable projection; show actual Scanning, Ready, Empty, recoverable error or Revoked; never imply stale content is playable; user files untouched.
- **Architecture/privacy:** one service-owned Playback/MediaSession authority, no independent UI queue/Voice-owned player, no backend/account/streaming/upload/identity. No permission result, raw voice/transcripts, song/artist/filename/path/URI, content or device identifiers in telemetry.
- **Accessibility:** use approved Hi-Fi/Phase-7 focus order and labels; >=48dp targets, 100/150/200% scaling, non-color-only cues, TalkBack/focus restoration require actual Compose/device verification.
