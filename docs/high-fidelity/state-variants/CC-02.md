- **Presentation:** Show the component's Pending/Loading text and disable duplicate mutation; never display success before owner acknowledgement.
- **Recovery:** On acknowledgement refresh source snapshot; on timeout/failure show typed recovery and preserve previous truthful state.
- **Entry:** Actual owning state transitions from UF-07; never an independently navigable screen.
- **Back/Exit:** Defer to approved owning WF Back behavior. In Driving, Back means immediate Exit; Voice Back means Cancel.
- **Acknowledgment/owner:** App + Playback Service; UI observes service/coordinator/platform truth without optimistic success.
- **Existing actions only:** no additional button, keyboard, deep menu, fake Android dialog or new destination.
- **TalkBack:** speak written state + action label in owning component; retain stable focus/reading order.
- **Minimum interactive size:** 48dp global; Driving 64dp controls / 72dp Mic / 56dp Exit.
- **Text 200%:** Compose reflow check required later; no image-only sign-off.
