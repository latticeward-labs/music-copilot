## Actual platform transition and return

### WF-06_SYSTEM_MEDIA_NOTIFICATION_CONTROLS / Media Notification controls
- Trigger: A valid active MediaSession exposes the platform notification surface.
- Handoff to REAL owner: Play/Pause/Next/Previous commands travel through Android MediaSession; the surface waits for acknowledgement.
- Authoritative playback/service state: Service owns queue/player/state and refreshes all app/system surfaces from one snapshot.
- Return recheck (never infer from onResume alone): Acknowledged command updates notification and app. Unavailable surface returns control to the app without fabricating stop.
- Safe terminal: MANUAL_PLAYBACK
- Retry/recovery bounds: A pending command is serialized; rejection/timeout refreshes truth before any safe retry.

### WF-06_SYSTEM_LOCK_SCREEN_CONTROLS / Lock-screen media controls
- Trigger: Device locks or screen turns off while a valid MediaSession exists.
- Handoff to REAL owner: Android renders lock-screen controls; the app does not invent or own this screen.
- Authoritative playback/service state: Playback continues from service truth; commands remain pending until acknowledgement.
- Return recheck (never infer from onResume alone): Unlock/app return reconnects to the complete current snapshot; surface absence is not playback failure.
- Safe terminal: MANUAL_PLAYBACK
- Retry/recovery bounds: Rejected/system-unavailable command refreshes state and restores reachable app controls.

### WF-06_SYSTEM_EXTERNAL_MEDIA_CONTROLS / External media keys and controller handoff
- Trigger: A supported Bluetooth/headset/vehicle media key issues a MediaSession command.
- Handoff to REAL owner: Android routes the command; no separate app player or queue is created.
- Authoritative playback/service state: The shared service validates, serializes and acknowledges the command.
- Return recheck (never infer from onResume alone): All visible surfaces refresh from the authoritative snapshot; unsupported/unavailable returns to app manual controls.
- Safe terminal: MANUAL_PLAYBACK
- Retry/recovery bounds: No optimistic duplicate command; safe retry only after refresh.
