## Actual platform transition and return

### WF-06_SYSTEM_PHONE_CALL_AUDIO_FOCUS / Phone Call and Audio Focus interruption
- Trigger: Transient/permanent Audio Focus loss, call, duck request or focus callback error.
- Handoff to REAL owner: Android supplies focus/call category only; Voice is canceled and no call identity is read.
- Authoritative playback/service state: Service pauses or ducks. Resume occurs only when all four guards pass and service acknowledges it.
- Return recheck (never infer from onResume alone): Valid transient gain may return to actual Playing; any failed guard or permanent loss remains Safe Paused with manual Resume.
- Safe terminal: SAFE_PAUSED
- Retry/recovery bounds: No hidden auto-retry. Manual Resume rechecks route/focus before command.

### WF-06_SYSTEM_WIRED_HEADSET_ROUTE_RECOVERY / Wired/headset disconnect and reconnect
- Trigger: Wired/headset route disconnects or reconnects.
- Handoff to REAL owner: Android route change invalidates the previous route generation immediately.
- Authoritative playback/service state: Service pauses at disconnect, cancels Voice and prevents speaker leakage.
- Return recheck (never infer from onResume alone): Reconnect rechecks route but never auto-resumes; explicit Play may resume after acknowledgement.
- Safe terminal: SAFE_PAUSED
- Retry/recovery bounds: Manual Play is the only resume attempt; a new loss returns immediately to Safe Paused.

### WF-06_SYSTEM_BLUETOOTH_ROUTE_RECOVERY / Bluetooth route loss and reconnect
- Trigger: Selected/current Bluetooth output route disconnects or reconnects.
- Handoff to REAL owner: Android route truth controls output; connection alone never opens Driving Mode.
- Authoritative playback/service state: Service immediately pauses on loss, invalidates the route and prevents speaker fallback leakage.
- Return recheck (never infer from onResume alone): Reconnect produces Safe Paused. Explicit manual Play revalidates route and waits for service acknowledgement.
- Safe terminal: SAFE_PAUSED
- Retry/recovery bounds: No automatic Resume. Failed manual Play stays Safe Paused with Exit/manual controls.
