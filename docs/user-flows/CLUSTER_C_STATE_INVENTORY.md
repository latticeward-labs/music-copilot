## State invariants

1. CC-05/06/07 are the only steady Driving Mode states required by the English MVP.
2. CC-02/03/08/09/10 are bounded truth-preserving states, not new destinations.
3. CC-11/12/17 are P1 and removable without affecting the P0 graph.
4. CC-13 is reachable from every Driving Mode or pending state.
5. CC-14 and CC-16 are controlled downstream handoffs; their detailed behavior is not invented in UF-07.
6. No state contains typing, Search, Queue/Browse list, nested menu, Settings, or automatic Driving Mode launch.
7. No state stores or emits personal media metadata, Bluetooth device identity, raw audio, or transcript.

## Inventory decision

**PASS.** CC-01 through CC-18 cover P0 manual entry, optional P1 suggestion, Playing/Paused/No Track, commands, pending/error recovery, immediate Exit, privacy, accessibility, and downstream handoffs without expanding MVP scope.
