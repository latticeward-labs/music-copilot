# STATE_ACTION_MATRIX — Canonical 126 States, 32 Frames and Android Handoff

**Issue #17 Phase 9** · Source: 126 canonical `HIFI_STATE_COVERAGE_REGISTER.json` states (45 dedicated, 61 component variants, 20 Android/system-only), plus 32 approved Low-Fi frames. No new State IDs or authority.

## Architecture precedence (binding)

- Live playback queue/item/position/error **MediaSessionService** via PlaybackGateway.snapshot, never the Player UI. Typed playback `lastError: AppError?` restricted to MediaItem/Playback/Interruption (PH10-MAJ-002 corrected).
- `VoiceSessionCoordinator` owns active Voice state, token and immutable `Confirming.options[1..2]` (PH10-MAJ-001 corrected). `VoiceFeedbackOverlay` is NOT a navigation destination; Back first cancels generation and returns to origin.
- Permission/Settings/notification/lockscreen/vehicle controls are system-only; no Android dialog mock; on return recheck actual platform state.
- Analytics comes only from the closed 8-event typed allowlist at application/domain. PrivacyGate sanitizes and optional TelemetrySink nonblocks; no personal content/position/audio/transcript/query/IDs.

## Quantitative and concurrency guards

1. **Playback ACK:** all manual/System/Voice commands converge on PlaybackCommandProcessor and MediaSessionService; serialized CommandId, last confirmed snapshot remains on failure; corrupted file `AppError.MediaItem`, route `AppError.Interruption` and playback `AppError.Playback` only; Controller errors remain connection-level.
2. **Previous >3 seconds** restarts current; otherwise prior valid queue item. Seek Back uses `PlaybackCommand.SeekBy(-10000)`; clamp actual duration in service. Service's queue/currentIndex/currentItem must agree; Room cannot become live queue truth.
3. **Voice:** push-to-talk only, ≤6s listening, one eligible Retry→attempt 2, one confirmation 1–2 options immutable and submitted via `confirm(token,optionIndex)`, no guessing unsupported/not-found. Optional TTS ≤one short sentence and its failure does not roll back acknowledged execution.
4. **Back/Exit:** Voice cancels/release capture/duck/stale callbacks first. Driving Exit immediate to recorded origin; no nested Voice destination, no Settings from Driving, no Android Auto.
5. **Interruption:** Bluetooth/wired route disconnected → Safe Paused immediately; reconnect never auto-plays. Resume needs explicit Play and ACK except separately valid transient four-guard focus policy. P1 cold restore can only prepare Paused, never auto-playing.
6. **Telemetry allowlist:** DrivingModeStarted, VoiceButtonPressed, IntentDetected, IntentFailed, CommandExecuted, ManualCorrection, PlayerError, SessionCompleted; enum/buckets only and no arbitrary map. **No telemetry hook** is a valid answer for Screens/Components not represented by these exact events.
